# Customer Shopping Behavior Analysis

An end-to-end data analytics project that analyzes customer shopping behavior using **Python, PostgreSQL, and Power BI**. The project focuses on data cleaning, preprocessing, exploratory analysis, SQL-based business analysis, and interactive dashboard development.

## 📌 Project Overview

The objective of this project is to analyze customer purchasing patterns and identify useful insights related to sales, customer segments, product preferences, subscription behavior, discounts, shipping methods, and age groups.

The dataset contains **3,900 customer purchase records** with **18 original columns** covering customer demographics, purchase details, and shopping behavior.

## 🎯 Objectives

- Clean and preprocess customer shopping data.
- Handle missing and inconsistent data.
- Perform exploratory data analysis using Python.
- Store and analyze the cleaned data using PostgreSQL.
- Answer important business questions using SQL.
- Create an interactive Power BI dashboard.
- Identify customer, product, sales, and subscription trends.
- Generate actionable business recommendations.

## 🗂️ Dataset

The dataset contains information related to:

### Customer Information
- Customer ID
- Age
- Gender
- Location
- Subscription Status

### Purchase Information
- Item Purchased
- Category
- Purchase Amount
- Season
- Size
- Color

### Shopping Behavior
- Review Rating
- Shipping Type
- Discount Applied
- Promo Code Used
- Previous Purchases
- Payment Method
- Frequency of Purchases

The dataset initially contained **37 missing values in the Review Rating column**.
